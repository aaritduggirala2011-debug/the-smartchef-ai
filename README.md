# Smart Chef Recipes

Build Smart Chef, an AI web app that turns the ingredients a user has on hand into recipes matched to their dietary needs and macro/nutrition goals, while tracking their macros over time. It's for health-conscious home cooks — especially macro-trackers, people with dietary restrictions, and novice cooks who want confidence-building, difficulty-matched meals.

Pages needed:

Landing/Welcome — value prop, sign-up/login CTA

Onboarding — collect dietary restrictions, daily macro/calorie targets, cooking skill level

Pantry Input — add/select ingredients on hand

Recipe Suggestions — recipes filtered by pantry + diet + remaining macros

Recipe Detail — instructions, macro breakdown, difficulty, substitutions, a "Log this meal" button

Macro Dashboard — daily/weekly macro intake tracked against targets, updated as meals are logged

Profile/Settings — diet preferences, macro targets, subscription tier

Main user action: Enter available ingredients + goals → get a matched recipe → log it to track daily macros against targets.

Visual style: Clean, warm, appetite-inducing — soft neutral background, fresh green and terracotta accents, rounded cards, friendly sans-serif type, food-forward imagery. Modern and approachable, not clinical.
